# STREET MASTER α

This project is based on [Back Of Your Hand](https://github.com/adam-lynch/back-of-your-hand) (licensed under the Mozilla Public License 2.0). It adapts the concept for taxi training with additional features:

- Facility and intersection based challenges with distance and time scoring.
- "Street Challenge" mode with highlighted locations on a Mapbox map.
- History stored in browser `localStorage` (no database required).
- Route search between two points using Mapbox Directions API.
- Adjustable search radius from **1 km** to **100 km**.
- Single player only; circle-shaped challenge areas.

To run, simply open `public/index.html` in a browser and provide a Mapbox access token when prompted.
